Log-axis label offsets

SetXAxis and SetYAxis inspect the active pad's log setting and set that axis's label offset to -0.010. Linear axes use the corresponding label offset from gStyle. This also applies through SetAxes. Z-axis behavior is unchanged.

Make the graph's pad current, enable log scaling, then style the axes:

canvas->cd();
graph->Draw("ALP");
gPad->SetLogx();  // Use SetLogy() for the Y axis, or enable both.
roothelper::SetAxes(graph);

Detection happens when styling, not on every repaint. After a later SetLogx or SetLogy call, call the corresponding styling function again. To override an offset, call SetLabelOffset after styling. The offset -0.010 reduces the gap in the reference plot without moving its X labels inside. The former value of -0.075 moved them inside; 0.001 left too much space. Check the rendering when changing font or layout.

11 pt preset

Set GraphicsSize::current = kGraphicsSize11pt before Prepare() and canvas creation. The alias g_size_11pt is also available. Text is scaled by 11/8 relative to the 8 pt preset at the same publication size. Final point size depends on the inserted figure size.

Install to the home directory

Build and install under ~/.local (run from the repository root):

cmake -S src -B build -DCMAKE_INSTALL_PREFIX=$HOME/.local
cmake --build build -j
cmake --install build

This installs headers to ~/.local/include/roothelper/ and shared libraries libroothelper_{graphics,container,data_saver,analysis}.so (RPATH $ORIGIN) to ~/.local/lib64/roothelper/. It also writes cling_libraries.h with the absolute library paths of the chosen prefix.

ROOT macros, library mode: put export ROOT_INCLUDE_PATH=$HOME/.local/include:$ROOT_INCLUDE_PATH in ~/.bashrc and write #include <roothelper/roothelper.h>. In cling the header loads the libraries; no gROOT or gSystem call is needed. For ACLiC (root macro.C+) also load the libraries at startup with gROOT->ProcessLine("#include <roothelper/cling_libraries.h>") in ~/.rootlogon.C; otherwise loading the compiled macro fails with an undefined roothelper::GraphicsSize::current.

User setup templates: cmake --install writes <prefix>/share/roothelper/setup/bashrc and setup/rootlogon.C from src/cmake/bashrc.in and rootlogon.C.in with absolute paths of the prefix, then prints the setup commands (append the bashrc, copy the rootlogon, link the fontconfig file), marking with "(done)" what ~/.bashrc, ~/.rootlogon.C and ~/.config/fontconfig/conf.d already have. Check (purpose: the templates alone make macros, ACLiC and the scripts work) with an empty home:

cmake --install build --prefix /tmp/rh
mkdir /tmp/home5 && cp /tmp/rh/share/roothelper/setup/rootlogon.C /tmp/home5/.rootlogon.C
cp /tmp/rh/share/roothelper/setup/bashrc /tmp/home5/.bashrc
env -i HOME=/tmp/home5 PATH=/usr/bin:/bin bash -c '. /usr/local/root/bin/thisroot.sh; . ~/.bashrc
  command -v ProcessPDF; root -l -b -q m.C; root -l -b -q m.C+'

Result: all three work; without .rootlogon.C ACLiC fails at link time.

Source mode (no libraries, slower): #include <roothelper/roothelper_source.h>. After changing headers, check that this mode still compiles, since include order matters there (run from a directory holding a macro m.C that includes the header):

ROOT_INCLUDE_PATH=$HOME/.local/include root -l -b -q m.C

Checked with a scratch prefix: interpreted macro 0.28 s (source mode 1.7 s), ACLiC with the logon, cmake --install --prefix relocation, and a CMake project including roothelper.h from two files.

CMake projects: configure with -DCMAKE_PREFIX_PATH=$HOME/.local (or export CMAKE_PREFIX_PATH) and write:

find_package(roothelper REQUIRED)
target_link_libraries(your_target PRIVATE roothelper::RootHelper)

The package config is installed to ~/.local/lib64/cmake/roothelper/ and finds ROOT (Core, Hist, Gpad) itself. Individual targets roothelper::Graphics, ::Container, ::DataSaver and ::Analysis are also exported. Verified with a consumer project built against a scratch install prefix.

Crowded labels: SetAxes (through AdjustAxisLabelSpace) lowers the primary divisions of a linear numeric axis until neighbouring labels are half a text height apart, keeping the secondary divisions; e.g. 0.709–0.759 goes from 0.005 to 0.01 steps (510 → 509). Interpreter (cling) timing

Purpose: compare JIT cost of the template API with a non-template (TObject*) variant, and of source inclusion with loading the compiled libraries. Per-step times come from TStopwatch around gInterpreter->ProcessLine:

ROOT_INCLUDE_PATH=<variant root> root -l -b -q inner.C        # #include "roothelper.h" (sources)
ROOT_INCLUDE_PATH=<build>/src/core/include root -l -b -q lib.C  # gSystem->Load + headers only
/usr/bin/time -f %e root -l -b -q user.C                          # whole macro, 7 runs

Result (ROOT 6.36.06): source inclusion about 1.6 s; libraries plus headers about 0.17 s. First call of a template per type: about 14 ms (source mode) or 47–58 ms (library mode); non-template calls about 1–8 ms.

With explicit instantiations in the library (ROOTHELPER_FOR_EACH_AXIS_TYPE), library-mode first calls of SetAxes take about 1.3 ms for listed types and about 22 ms for others (e.g. TH1S), measured with inst.C in the same way.

PDF figures: outlines and SVG (ProcessPDF)

script/ProcessPDF is installed to <prefix>/bin with the libraries. For each PDF it moves the original to rawpdf/, rewrites the PDF with the crop box as the page (ROOT PDFs have an A4 media box and a 90° rotation) and all fonts embedded, writes an outlined copy to olpdf/ (ghostscript -dNoOutputFonts) and an SVG of that copy to svg/ (one file per page; width and height in pt):

export PATH=$HOME/opt/roothelper/bin:$PATH
ProcessPDF figs/plot.pdf figs/other.pdf

ROOT does not embed fonts. Ghostscript uses Nimbus Sans/Roman/Mono and Standard Symbols PS for the base 14 fonts. poppler viewers on AlmaLinux 10 substitute Noto Sans for Symbol (Greek letters change shape, ∫ disappears), so the original is not a reliable reference there unless the fontconfig file below is enabled.

Check (purpose: confirm that outlining and SVG keep the glyph shapes). Render the original with ghostscript and the outputs with poppler and librsvg at 600 dpi, then compare with a 2 px tolerance:

gs -q -dNOPAUSE -dBATCH -sDEVICE=pnggray -r600 -dUseCropBox -dTextAlphaBits=4 -dGraphicsAlphaBits=4 -sOutputFile=ref.png rawpdf/plot.pdf
pdftoppm -r 600 -gray -png -singlefile olpdf/plot.pdf o
rsvg-convert -d 600 -p 600 -b white svg/plot.svg -o s.png
pdffonts olpdf/plot.pdf    # lists no fonts

Result on LaserLabLinux0 (gs 10.02.1, poppler 24.02): the processed, outlined and SVG files of a ROOT plot match the reference with no differing pixels; for a LaTeX PDF the SVG differs only by a sub-pixel shift. Inkscape opens the SVG at the PDF page size.

Substitute fonts for the base 14 (font/)

font/ holds the URW base 35 fonts (release 20200910, AGPL-3.0 with a font embedding exception, see font/LICENSE) that ghostscript uses for the PDF base 14: Nimbus Sans, Nimbus Roman, Nimbus Mono PS, Standard Symbols PS and D050000L, as OpenType. Downloaded from the upstream tag (purpose: the same outlines that ProcessPDF produces):

B=https://raw.githubusercontent.com/ArtifexSoftware/urw-base35-fonts/20200910
for f in NimbusSans-{Regular,Italic,Bold,BoldItalic} NimbusRoman-{Regular,Italic,Bold,BoldItalic} \
         NimbusMonoPS-{Regular,Italic,Bold,BoldItalic} StandardSymbolsPS D050000L; do
  curl -fLO $B/fonts/$f.otf
done
curl -fLO $B/LICENSE; curl -fLO $B/COPYING

The installation puts them in <prefix>/share/roothelper/fonts/ and writes <prefix>/share/roothelper/fontconfig/99-roothelper-fonts.conf, which adds that directory and replaces the families Helvetica, Times, Courier, Symbol and Zapf Dingbats by the substitutes even when those fonts are installed. Enable it for the user (Linux; Inkscape, Evince and other fontconfig programs):

mkdir -p ~/.config/fontconfig/conf.d
ln -s ~/opt/roothelper/share/roothelper/fontconfig/99-roothelper-fonts.conf ~/.config/fontconfig/conf.d/
fc-match Helvetica    # NimbusSans-Regular.otf

Check (purpose: substitutes win over installed fonts). With a scratch HOME (XDG_CONFIG_HOME, XDG_DATA_HOME) holding copies of DejaVu renamed to Helvetica, Times and Symbol, export an SVG with text in those families and list the fonts:

inkscape text.svg --export-type=pdf --export-filename=out.pdf
pdffonts out.pdf

Result (Inkscape 1.x AppImage): without the file the renamed fonts are embedded; with it, NimbusSans-Regular, NimbusRoman-Regular and StandardSymbolsPS. On Windows and macOS install the OpenType files and choose the Nimbus families by name; the replacement rule is not tested there.
